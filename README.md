# MarginReach

Project website for:

**MarginReach: Margin-Aware Residual Reinforcement Learning for Pre-Harvest Reaching in Deformable Fruit Canopies**

This directory is a static project website. Open `index.html` locally or publish the `paper/website` directory with GitHub Pages or another static host.

## Structure

- `index.html` - project homepage
- `assets/css/styles.css` - responsive site styling
- `assets/js/main.js` - mobile navigation behavior
- `assets/images/` - paper figures used by the site
- `assets/paper/marginreach-paper.pdf` - manuscript PDF synced from `paper/RAL/root.pdf`
- `video/simulation_experiment.mp4` - simulation experiment video, H.264 MP4, 1280 x 720, 30 fps
- `video/real_experiment.mp4` - real-robot experiment video, H.264 MP4, 1920 x 1080, 30 fps

Update the author list, public code link, and BibTeX entry after anonymized review if the public release needs them.
